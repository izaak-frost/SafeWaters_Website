OPTIONAL BRAND ASSETS

If you have a SafeWaters logo, place it in this folder as:

  safewaters-logo.png

It will then be available publicly at:

  https://safewaters.uk/safewaters-logo.png

That URL can also be used in your Supabase email templates.

The starter site currently uses a text/shape brand mark, so the site works
without adding an image.
